# 极光海洋 · WebGL2 原生 GLSL

复刻「WebGL2 原生 GLSL 极光海洋」的单文件实时渲染 demo：体积极光、程序化海面、月亮辉光全部在 fragment shader 里手写（FBM 噪声 + 光线步进），零贴图、零模型、零依赖。

**在线体验**：<https://wangxp7.github.io/YiQiVibe-WBGL2-GLSL-ocean-ZG5.3F/>

## 运行

双击 `index.html` 即可（需支持 WebGL2 的现代浏览器），或访问上面的 GitHub Pages 站点。

## 操作

- 按住鼠标拖动：环视海面
- 控制面板：分辨率（30%–100%）、自动适配、极光强度、海浪高度、时间速度

## 技术要点

- **体积极光**：沿视线光线步进 28 步，域扭曲 FBM 生成光团 + 帘状条纹，高度决定颜色梯度；反射用 12 步廉价版本
- **海面**：射线与平面求交，FBM 波高场差分求法线，Fresnel 混合深水色与天空/极光/月亮反射，地平线雾统一海天交界
- **渲染管线**：`gl_VertexID` 凭空生成的全屏三角形，无任何顶点缓冲；ACES 色调映射 + gamma 校正 + 逐像素抖动去色带
- **自适应**：每秒按 FPS 自动升降渲染分辨率，右下角实时显示 FPS 与分辨率
